## Why this line

Performance reviews run on evidence a manager personally witnessed:
ratings, calibration, the dreaded 'visibility' note. This review takes
that machinery literally — the employee is so good he keeps getting
promoted, and so invisible he lands on a plan for it. The joke is the
collision: twice in 18 months up the ladder, and the formal record
still insists he was never in the room.
